# Roadmap — Stages 1 to 3

| | Stage 1 (13 Nov) | Stage 2 (18 Nov) | Stage 3 (26 Nov) |
|---|---|---|---|
| Statement | Basic Resume Screening and Skill Matching System (Theme 3) | AI-Based Personalized Learning and Assessment Platform (AI-Powered Smart Education) | AI-Based Personalized Career Guidance and Skill Gap Prediction (Generative AI and Intelligent Systems) |

## Rule 12 (progressive improvement)
Technical depth: rules -> learner model -> RAG/LLM. Integration: single tool -> learning loop -> guidance platform. Real-world use: self-check -> upskilling -> career planning.

## Fallback Stage 2 framing
If the mentor rejects the education framing: Cybersecurity & Digital Safety -> Secure Digital Document Verification Platform (verify resume/certificate claims), which still leads to Stage 3 "Intelligent Document Understanding and Automated Information Extraction".
